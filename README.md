# RCIA Dashboard (React)

A premium, trust-minimized dashboard for monitoring the Real-world Capital Intelligence Agent.

## 🚀 Features

- **Live Agent Status**: Monitor current operating mode (GROWTH, DEFENSIVE, YIELD, HEDGE).
- **Market Metrics**: Real-time visualization of asset prices and volatility.
- **Trust Artifacts**: Inspect on-chain / simulated ERC-8004 validation artifacts and decision hashes.
- **Risk Monitoring**: Real-time feedback from the embedded risk engine and guardrails.

## 🛠️ Quick Start

### 1. Installation

```bash
cd RCIA_dash
npm install
```

### 2. Development

```bash
npm run dev
```

### 3. Build for Production

```bash
npm run build
```

## 🎨 Design System

Built with **Vanilla CSS** for maximum performance and customization.

- **Dark Mode**: High-contrast, easy-to-read dark theme.
- **Glassmorphism**: Modern UI effects for a premium feel.
- **Typography**: Optimized Inter font stack.

## 📊 Integrations

- **Lucide React**: Premium iconography.
- **Recharts**: High-performance data visualization.
